# GlowFlow redesign package

Start here:
1. `AGENT-PROMPT.md`: paste into your coding agent after copying this folder to `docs/design/` in the repo.
2. `HANDOFF.md`: the full spec (brand rules, screen to route map, implementation order, open questions).
3. `screens/`: open any `.html` file in a browser. `screens/png/` has screenshots of each.

Folders: `brand/` (logo, icons, OG image, fonts for mockups), `tokens/` (drop-in globals.css, fonts.ts, logo.tsx, tokens.json), `motion/` (videos and posters), `screens/` (HTML mockups).
